# Super Duper Compatibility

Public compatibility database, recommended profiles and static catalogue for
the Super Duper iPhone app emulator.

The repository contains no IPA archives, game assets, decrypted files, product
keys, personal save data or private diagnostic logs.

## Contributing

See [`compatibility-db/README.md`](compatibility-db/README.md) for record rules,
the data layout and local validation commands.

The catalogue is published automatically to GitHub Pages after each push to
`main`.
