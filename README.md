# Super Duper Compatibility

Public Android compatibility database, recommended profiles and static
catalogue for the Super Duper iPhone app emulator.

The repository contains no IPA archives, game assets, decrypted files, product
keys, personal save data or private diagnostic logs.

## Contributing

See [`compatibility-db/README.md`](compatibility-db/README.md) for record rules,
the data layout and local validation commands.

The catalogue is published automatically to GitHub Pages after each push to
`main`. It is designed after the information hierarchy of the touchHLE AppDB:
apps, versions and version-specific reports.

The initial catalogue imports app metadata and Android-only touchHLE reference
reports. Those imported reports are clearly labelled as references; they are
not Super Duper test results. Android ratings in this project are only assigned
after testing Super Duper itself.

See [ATTRIBUTION.md](ATTRIBUTION.md) for the required attribution and licence
terms for the imported data.
