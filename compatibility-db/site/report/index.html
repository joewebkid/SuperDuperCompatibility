Отчёт о совместимости

Опиши проверенную версию IPA. Отчёт сначала попадёт в черновой Pull Request и появится в базе только после проверки человеком.

Выбери игру из подсказок — Bundle ID заполнится автоматически, если он есть в базе. Сверь версию со своей IPA.

Не прикладывай личные данные, приватные логи, сохранения или IPA. Вход в GitHub не требуется.
